# HR Analytics Dashboard | Power BI

## Overview

This project focuses on workforce analytics using Power BI. The dashboard provides insights into employee attrition, workforce demographics, job satisfaction, and organizational performance.

## Business Problem

Employee attrition impacts productivity and increases recruitment costs. HR teams require actionable insights to improve employee retention and workforce management.

## Tools & Technologies

- Power BI
- DAX
- Data Modeling
- Excel / CSV

## Key KPIs

- Total Employees
- Attrition Count
- Attrition Rate
- Average Age
- Job Satisfaction Score
- Department-wise Attrition

## Dashboard Features

- Employee Attrition Analysis
- Department-wise Analysis
- Gender Distribution
- Education Analysis
- Age Group Analysis
- Job Role Analysis

## Key Insights

- Identified departments with higher attrition rates.
- Analyzed employee demographics.
- Evaluated job satisfaction trends.
- Highlighted factors influencing employee turnover.
